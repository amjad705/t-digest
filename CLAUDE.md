# T Digest

This repo holds the "T Digest" daily news briefing: HTML templates
(`templates/`), Node render/send scripts (`scripts/`), and the scheduled-task
instructions (`tasks/*/SKILL.md`). The `tasks/` paths point at the user's
Windows desktop.

When asked for the T Digest Broadsheet in a cloud session, always use the cloud
version in `cloud/` (see `cloud/README.md`): the user wants this format and
fill kept permanently. Do not change the desktop zoom values in
`templates/T Digest.html`.
